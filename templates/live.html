💡 How to Use Live Recording

Option 1: Desktop Client (Recommended)

Download and run the desktop client on your computer to capture system audio during meetings:

  1. Install: pip install -r client/requirements.txt
  2. Run: python client/audio_capture.py
  3. Select your audio device (use "Stereo Mix" or virtual cable for system audio)
  4. Start your meeting and the client will capture audio automatically
